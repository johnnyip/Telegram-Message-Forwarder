# Operational enhancements 2026-11-17

- All standard logger handler output and structured event logs redact Bot API tokens and environment credential values. Third-party HTTP logs default WARNING. Existing stored logs are not rewritten or deleted; coordinate any credential rotation separately.
- Listener edits are queued durably in the existing guarded spool SQLite ledger before returning. Replay every 5s, bounded 16-event pass, 30s per-event deferral, 24h maximum pending age. Each event snapshots route names/targets; current policy must match and no unexpected target mapping may transport. All expected target/copy progress must acknowledge before done; prior/newer revision checks and uncertain-reply fencing remain in edit_updates. Expired/policy-changed rows are retained 7 days. Per-source/album locks replace a single process-wide history lock.
- Non-forum topic-discovery failure is negative-cached for 15 minutes; normal general sends unchanged. Cache expires so later forum enablement is discovered.
- Control socket health retains status=ok as liveness; readiness, last poll age, consecutive errors, inbox age and task/update state totals distinguish service progress. Poll retry uses capped exponential backoff+jitter; safe diagnostic codes expose conflict/ownership/auth failures without secrets.
- GC runs each 60s; successful full batches drain every 2s. Each scan remains bounded to 64 files, 1GiB and 2s checks. Existing 24h grace, ownership signatures, terminal references, leases and fail-closed rules preserved. Due-order scheduling and deferred blocked entries prevent one undeletable file starving others. due_count exposes eligible backlog; referenced/uncertain files are never swept by age.

Regression suite covers redaction including exceptions/arguments, durable dedup/restart/expiration, late target mappings, route drift, source locks, per-copy acknowledgement, negative-cache refresh, control readiness and GC follow-up interval. No manual container builds/probes; existing Jenkins builds and immutable image publication own deployment.
